# 🚀 Rezit

### SaaS para negocios de servicios

**Rezit** es una plataforma SaaS que estoy construyendo para ayudar a negocios de servicios a gestionar sus citas, clientes, ventas y operaciones.

Está orientada inicialmente a negocios como:

* 💈 Barberías
* 💇 Salones de belleza
* 🐾 Veterinarias
* 🖋️ Estudios de tatuajes
* 🦷 Consultorios

El proyecto utiliza una arquitectura basada en **Laravel**, con una aplicación central y sistemas independientes para cada negocio.

### Stack principal

`Laravel` · `Livewire` · `Filament` · `Flux` · `Tailwind CSS` · `MySQL`

🌐 **[rezit.co](https://rezit.co)**
